基础用法 ​

使用 弹窗模式 (FilePreviewModal):

tsx
import { useState } from 'react'
import { FilePreviewModal } from '@opsbli/react-file-preview'
import '@opsbli/react-file-preview/style.css'

function App() {
  const [isOpen, setIsOpen] = useState(false)
  const files = [
    { url: 'https://example.com/document.pdf', name: 'document.pdf' }
  ]

  return (
    <>
      <button onClick={() => setIsOpen(true)}>预览文件</button>
      <FilePreviewModal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        files={files}
        currentIndex={0}
      />
    </>
  )
}
vue
<script setup>
import { ref } from 'vue'
import { FilePreviewModal } from '@opsbli/vue-file-preview'
import '@opsbli/vue-file-preview/style.css'

const isOpen = ref(false)
const files = [
  { url: 'https://example.com/document.pdf', name: 'document.pdf' }
]
</script>

<template>
  <button @click="isOpen = true">预览文件</button>
  <FilePreviewModal
    :is-open="isOpen"
    :files="files"
    :current-index="0"
    @close="isOpen = false"
  />
</template>

使用 嵌入模式 (FilePreviewEmbed) — 将预览直接内联到页面任意容器:

tsx
import { FilePreviewEmbed } from '@opsbli/react-file-preview'
import '@opsbli/react-file-preview/style.css'

function Detail() {
  const files = [
    { url: 'https://example.com/document.pdf', name: 'document.pdf' }
  ]

  return (
    <div style={{ width: '100%', height: 520 }}>
      <FilePreviewEmbed files={files} />
    </div>
  )
}
vue
<script setup>
import { FilePreviewEmbed } from '@opsbli/vue-file-preview'
import '@opsbli/vue-file-preview/style.css'

const files = [
  { url: 'https://example.com/document.pdf', name: 'document.pdf' }
]
</script>

<template>
  <div style="width: 100%; height: 520px">
    <FilePreviewEmbed :files="files" />
  </div>
</template>

支持的文件类型 ​

  • 图片：JPG, PNG, GIF, WebP, SVG, BMP, ICO
  • 视频：MP4, WebM, OGG, MOV, AVI, MKV, M4V, 3GP, FLV
  • 音频：MP3, WAV, OGG, M4A, AAC, FLAC
  • 文档：PDF, Word (DOCX), Excel (XLSX), PowerPoint (PPT/PPTX), Outlook (MSG)
  • 电子书：EPUB, MOBI, AZW, AZW3, KF8
  • 字体：TTF, OTF, WOFF, WOFF2
  • CAD / 3D 模型：DXF, STL, OBJ, GLTF, GLB
  • 结构化数据：JSON, CSV, TSV, XML
  • 字幕 / 歌词：SRT, WebVTT, LRC, ELRC, ASS, SSA, TTML, DFXP
  • 压缩包：ZIP
  • 文本：Markdown, 代码文件（40+ 种语言语法高亮，含 Vue/Svelte 组件、Shell/Batch 脚本），各类纯文本

包架构 ​

@opsbli/file-preview-core    # 框架无关的核心工具（types/工具函数/PDF 配置）
       │
       ├── @opsbli/react-file-preview   # React 18+ 版本
       └── @opsbli/vue-file-preview     # Vue 3 版本

两个 UI 包共享同一份纯 TS 工具与类型定义，并按各自框架惯例提供等价能力。
